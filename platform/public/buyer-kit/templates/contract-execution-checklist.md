# 采购合同执行件归档检查表

只有全部项目真实完成后，运营人员才可在 Q-Tail 将合同标记为已签署。

- [ ] 买方外部 Gate 1 已通过，原件/签署件/审核见证哈希均可核验
- [ ] 买方外部 Gate 2 已通过，独立复现与冻结协议可核验
- [ ] 买方外部 Gate 3 已通过，真机、安全、发票成本与采购签字可核验
- [ ] 当前 Terms、Privacy、DPA 版本已被买方接受
- [ ] 数据权利、部署、驻留、保留、删除和子处理方资料已批准
- [ ] 最终 SOW 的机器人、任务、预算、数据格式、验收、价格和责任边界无空白
- [ ] 双方已在 Q-Tail 之外完成真实签署或盖章
- [ ] 执行合同编号/存档引用已取得
- [ ] 执行合同 PDF 或签署包 SHA-256 已独立计算
- [ ] 服务方签署人完整姓名已记录
- [ ] 服务方独立签署凭证文件/平台回执 SHA-256 已记录
- [ ] 买方签署人完整姓名已记录
- [ ] 买方独立签署凭证文件/平台回执 SHA-256 已记录，且与服务方凭证哈希不同
- [ ] 合同生效日已记录
- [ ] 发票、付款、退款和税务责任与真实商户/银行流程一致

禁止事项：不得使用本地仿真、Docker fixture、空白模板、单方草案、示例 URL、聊天确认、同一份单方凭证或未签署文件替代买方证据和双方执行合同。
