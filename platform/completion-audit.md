The controlled MVP is implemented and has been exercised end to end in local Docker. RC18–RC22 records remain historical evidence of release packaging and the former controlled pilot, but that pilot is no longer the current runtime. The evidence cycle produced 64 Sawyer/MuJoCo synthetic trajectories (3,285 frames), validated LeRobot/RLDS formats, retrained the controlled Gate 2 comparison directly from that immutable Gate 1 package, and exposed the fixed package to Pro users. RC19 additionally turns the supported Sawyer/MetaWorld source into request-specific 1–64 episode RLDS-compatible API deliveries after Q-Tail allocation and exact source verification. RC21 added a deterministic buyer pilot kit; RC22 added its executable buyer-backend Gate 1 validator, which rejects blank/tampered inputs and still requires external buyer signoff. These records prove the software and local simulator workflow, not current public availability, procurement performance, or a real signature. The project must not yet be represented as fully buyer-validated: buyer-selected production-backend trajectories, independent closed-loop reproduction, real-robot trials, verified commercial cost reduction, an actual executed buyer agreement, and an explicitly authorized trusted public HTTPS origin are still outstanding.
